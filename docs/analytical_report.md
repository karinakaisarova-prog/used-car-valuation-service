Аналитический отчет: Разработка модели оценки стоимости автомобилей
1. Цель проекта Целью работы является построение модели машинного обучения для определения рыночной стоимости автомобиля на основе его технических характеристик. Основные требования заказчика: высокое качество предсказания (RMSE менее 2500), высокая скорость обучения и минимальное время отклика модели.
2. Данные и предобработка В ходе работы использовались исторические данные о характеристиках автомобилей. Основные этапы обработки включали:
Заполнение пропусков в признаках типа кузова, коробки передач и информации о ремонте значением "unknown".
Удаление неинформативных признаков, таких как количество фотографий (NumberOfPictures), которые не влияют на стоимость.
Фильтрация аномалий: удаление записей с некорректным годом регистрации и мощностью двигателя (менее 50 и более 2500 л.с.).
Устранение мультиколлинеарности: удаление признака "модель" из-за его избыточной связи с маркой и типом кузова.
3. Сравнение моделей Было проведено обучение трех моделей: Линейной регрессии, CatBoost и LightGBM. Оценка производилась по метрике RMSE и времени работы.
Результаты на тестовой выборке:
Линейная регрессия: RMSE = 2842.88 (не соответствует требованию < 2500).
LightGBM: RMSE = 1602.34, время обучения 10.50 сек.
CatBoost: RMSE = 1698.97, время обучения 9.27 сек.
4. Итоговое решение Для внедрения в сервис рекомендована модель CatBoost. Несмотря на небольшое преимущество LightGBM в точности, CatBoost показал лучший баланс между качеством (RMSE ≈ 1699) и скоростью обучения. Это критически важно для эффективной работы приложения и регулярного обновления данных.
