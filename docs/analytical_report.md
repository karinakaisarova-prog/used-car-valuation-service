# Аналитический отчет: Разработка модели оценки стоимости автомобилей

## 1. Постановка задачи
Целью данного проекта является построение модели машинного обучения для определения рыночной стоимости автомобилей с пробегом для сервиса «Не бит, не крашен». Основными приоритетами для бизнеса являются:
* **Качество предсказания:** значение метрики RMSE должно быть строго менее 2500.
* **Скорость обучения:** минимизация времени настройки модели на новых данных.
* **Скорость предсказания:** обеспечение быстрого отклика для конечного пользователя приложения.

## 2. Предобработка и анализ данных
В ходе исследования был выполнен полный цикл подготовки данных:
* **Очистка:** устранены пропуски в характеристиках (тип кузова, трансмиссия, модель) путем заполнения значением "unknown".
* **Фильтрация:** удалены неинформативные признаки (количество фотографий) и записи с аномальными значениями мощности (вне диапазона 50–2500 л.с.) и года регистрации.
* **Борьба с мультиколлинеарностью:** на основе анализа матрицы корреляции Phik был удален признак модели автомобиля, имеющий избыточную связь с брендом и типом кузова.

## 3. Сравнение моделей
Для решения задачи тестировались алгоритмы линейной регрессии и градиентного бустинга (CatBoost, LightGBM). Итоговые показатели моделей на тестовой выборке:

| Модель | RMSE | Время обучения (сек) | Соответствие критериям |
| :--- | :---: | :---: | :--- |
| **Linear Regression** | 2842.88 | 12.28 | Не соответствует порогу качества |
| **LightGBM** | 1602.34 | 10.50 | Соответствует всем критериям |
| **CatBoost** | 1698.97 | 9.27 | **Оптимальный выбор** |

## 4. Итоговое заключение
Для внедрения в систему рекомендована модель **CatBoost**.

**Обоснование выбора:**
1. **Эффективность:** модель продемонстрировала самое низкое время обучения (**9.27 сек**), что критически важно для производительности сервиса при масштабировании.
2. **Надежность:** показатель RMSE составляет **1698.97**, что значительно превосходит требуемый порог в 2500 и обеспечивает высокую точность оценки для клиентов.
3. **Готовность к эксплуатации:** использование пайплайнов обработки данных гарантирует стабильную работу модели без риска утечки данных при предсказании на новых объектах.
