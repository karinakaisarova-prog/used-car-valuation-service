# Определение рыночной стоимости автомобилей с пробегом

## Описание проекта
Сервис по продаже автомобилей с пробегом «Не бит, не крашен» разрабатывает приложение для привлечения новых клиентов. В нем пользователи могут быстро узнать рыночную стоимость своего автомобиля. В рамках проекта необходимо построить модель машинного обучения, которая определит цену на основе технических характеристик и комплектации.

Критерии, важные для заказчика:
- Качество предсказания (метрика RMSE должна быть меньше 2500).
- Скорость предсказания модели.
- Время обучения модели.

## Данные
Для работы использованы исторические данные сервиса:
- Признаки: модель, тип кузова, год и месяц регистрации, тип коробки передач, мощность (л.с.), пробег, тип топлива, бренд и информация о ремонте.
- Целевой признак: Price (цена в евро).

## Технологический стек
- Python
- Библиотеки обработки: pandas, numpy
- Анализ данных и визуализация: matplotlib, seaborn, phik (анализ мультиколлинеарности)
- Машинное обучение: scikit-learn (Pipelines, ColumnTransformer), CatBoost, LightGBM.

## Результаты исследования
По итогам тестирования моделей градиентного бустинга и линейной регрессии были получены следующие показатели:

| Модель | RMSE | Время обучения (сек) |
| :--- | :---: | :---: |
| Линейная регрессия | 2842.88 | 12.28 |
| CatBoost | 1698.97 | 9.27 |
| LightGBM | 1602.34 | 10.50 |

Для итогового внедрения рекомендована модель **CatBoost**. Она показала высокую точность (RMSE ≈ 1699 на тестовой выборке ) при лучшей скорости обучения, что полностью соответствует требованиям заказчика.
